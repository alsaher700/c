# طقس غزة — تصميم يومي

بطاقة طقس بمقاس منشور إنستغرام (1080×1350) تعرض:

- اليوم والتاريخ الميلادي والهجري (تقويم أم القرى)
- درجة الحرارة العظمى والصغرى وحالة الجو، مع الرطوبة وفرصة المطر ووقتي الشروق والغروب
- توقعات ٧ أيام مع شريط يوضح مدى الحرارة لكل يوم
- حديث شريف بنصه كما نشرته [موسوعة الأحاديث النبوية](https://hadeethenc.com/ar/browse/hadith/65527)
- رمز QR يفتح صفحة «طقس غزة» على Google مباشرةً

## الملفات

| الملف | الوظيفة |
|---|---|
| `template.html` | التصميم (الألوان، الخطوط، الأيقونات، التخطيط) |
| `data.json` | بيانات الطقس المعروضة |
| `render.js` | يدمج البيانات في التصميم ويصدّر صورة PNG |
| `output/` | الصور الناتجة |

## التحديث

```bash
npm install
npx playwright install chromium   # مرة واحدة فقط إن لم يكن متصفح Playwright مثبتاً

node render.js          # يصدّر الصورة من data.json
node render.js --live   # يجلب توقعات اليوم من Open-Meteo أولاً ثم يصدّر الصورة
```

- `SCALE=1 node render.js` يصدّر بالحجم الأصلي 1080×1350 بدل الدقة المضاعفة.
- عند عدم توفر الاتصال بـ Open-Meteo يُستخدم `data.json` تلقائياً.
- لتعديل البيانات يدوياً: غيّر القيم في `data.json`. الحالات المتاحة للطقس:
  `clear` صحو، `sunny` مشمس، `partly` غائم جزئياً، `cloudy` غائم، `fog` ضباب،
  `drizzle` رذاذ، `rain` ماطر، `snow` ثلوج، `storm` عواصف رعدية.

## مصدر بيانات ٩ نوفمبر ٢٠٢٦

توقعات Weather Underground لمدينة غزة، وهي من شركة The Weather Company التي يعرض
Google بياناتها في بطاقة الطقس. حُوّلت الدرجات من فهرنهايت إلى مئوية وقُرّبت.
وقتا الشروق والغروب محسوبان فلكياً لإحداثيات مدينة غزة.
